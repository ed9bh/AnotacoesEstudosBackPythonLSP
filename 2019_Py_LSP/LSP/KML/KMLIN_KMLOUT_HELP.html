KMLIN & KMLOUT para AutoCAD

Este documento descreve o funcionamento dos comandos LISP kmlIN e kmlOUT, projetados para facilitar a troca de informações entre o AutoCAD e o Google Earth.

Comando: kmlOUT (Exportar para KML)

Descrição:
Este comando exporta entidades selecionadas do seu desenho no AutoCAD (DWG) para um arquivo KML, que pode ser visualizado no Google Earth ou outros softwares de geoprocessamento.

Entidades Suportadas: Linhas, Polilinhas (2D e 3D), Pontos e Textos.

Como Usar:

  1. Digite kmlOUT no prompt de comando do AutoCAD e pressione Enter.
  2. Selecione o Fuso (UTM): Será solicitado que você escolha o fuso UTM correto para a sua área de trabalho.
  3. Selecione o Hemisfério: Informe se as coordenadas são do Hemisfério Sul (S) ou Norte (N).
  4. Selecione o DATUM: Escolha o sistema de referência geodésico (ex: Sirgas-2000, sAd-69).
  5. Selecione as Entidades: O programa pedirá para você selecionar os objetos no desenho que deseja exportar.
  6. Salvar o Arquivo: Uma janela de diálogo aparecerá para que você escolha o local e o nome do arquivo .kml a ser salvo.

Detalhes Importantes:
O script preserva as cores das entidades do AutoCAD, incluindo cores definidas por camada (ByLayer), por bloco (ByBlock), e cores diretas (TrueColor), convertendo-as para o formato correto no KML.

Comando: kmlIN (Importar de KML)

Descrição:
Este comando importa geometrias (Placemarks) de um arquivo KML para o seu desenho do AutoCAD, criando as entidades correspondentes.

Como Usar:

  1. Digite kmlIN no prompt de comando e pressione Enter.
  2. Configure a Conversão: Assim como na exportação, você precisará informar o Fuso, Hemisfério e DATUM para que as coordenadas geográficas (Latitude/Longitude) do KML sejam convertidas corretamente para o sistema UTM do seu projeto.
  3. Selecione o Arquivo: Uma janela de diálogo será aberta para você selecionar o arquivo .kml que deseja importar.

Detalhes Importantes:
O script lê os pontos e linhas dentro dos "Placemarks" do KML e os desenha no Model Space do AutoCAD. As cores definidas nos estilos do KML também são aplicadas às entidades criadas.

Notas Adicionais

  • Dependência: Este script requer o arquivo utm-geo_conversor.lsp no mesmo diretório ou em um caminho de suporte do AutoCAD para funcionar corretamente, pois ele é responsável pelas conversões de coordenadas.
  • Configuração Essencial: Para que os comandos LISP funcionem corretamente, a pasta contendo os arquivos LISP (KMLIN_KMLOUT.lsp e utm-geo_conversor.lsp) deve ser incluída no 'Support File Search Path' do AutoCAD (vá em Options > Files > Support File Search Path). Caso contrário, os comandos podem falhar ao serem carregados ou executados.
